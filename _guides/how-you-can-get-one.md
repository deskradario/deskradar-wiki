There are three ways to get a DeskRadar64. Pick the path that fits you, then follow the <a href="{{ '/guides/build-guide/' | relative_url }}">Build Guide</a> from step 1.

---

## Option 1 — Buy from the Store (Easiest)

Buy the enclosure and parts kit directly from the DeskRadar Etsy store. You get everything you need to assemble and run the device — no hunting down individual components.

**What you'll need from the store:**
- Enclosure and parts kit from <a href="https://shop.deskradar.io" target="_blank" rel="noopener noreferrer">shop.deskradar.io</a>
- A computer to flash the Pi image and install firmware

**Steps:**
1. Order from the store.
2. Flash the <a href="{{ '/pi_image/' | relative_url }}">DeskRadar Pi image</a>.
3. Install the <a href="{{ '/guides/install-circuitpython/' | relative_url }}">MatrixPortal firmware</a>.
4. Assemble using the <a href="{{ '/guides/construction-instructions/' | relative_url }}">Construction Instructions</a>.
5. Follow the <a href="{{ '/guides/initial-setup/' | relative_url }}">Initial Setup guide</a> to configure your location.

---

## Option 2 — Print Enclosure + Source Parts

Print the housing yourself and order all components from the bill of materials. Similar cost to Option 1 if you have a printer — and you control the material and finish.

**What you'll need:**
- 3D printer (or a local print service)
- STL files from <a href="https://www.printables.com/model/1704248-deskradar64-full-housing" target="_blank" rel="noopener noreferrer">Printables</a>
- All parts from the <a href="{{ '/hardware/' | relative_url }}">Hardware & Bill of Materials</a> page

**Steps:**
1. Download and print the STL files from Printables.
2. Order parts from the BOM.
3. Flash the <a href="{{ '/pi_image/' | relative_url }}">DeskRadar Pi image</a>.
4. Install the <a href="{{ '/guides/install-circuitpython/' | relative_url }}">MatrixPortal firmware</a>.
5. Assemble using the <a href="{{ '/guides/construction-instructions/' | relative_url }}">Construction Instructions</a>.
6. Follow the <a href="{{ '/guides/initial-setup/' | relative_url }}">Initial Setup guide</a> to configure your location.

---

## Option 3 — Full DIY

Build everything from scratch — the right path if you want to understand the full system or modify it. Same parts as Option 2, but read through the <a href="{{ '/architecture.html' | relative_url }}">Architecture</a> and <a href="{{ '/source.html' | relative_url }}">Source Code</a> pages alongside the build.

**What you'll need:**
- All parts from the <a href="{{ '/hardware/' | relative_url }}">Hardware & Bill of Materials</a> page
- Enclosure: print from <a href="https://www.printables.com/model/1704248-deskradar64-full-housing" target="_blank" rel="noopener noreferrer">Printables</a> or order from the <a href="https://shop.deskradar.io" target="_blank" rel="noopener noreferrer">store</a>

**Steps:** Follow the <a href="{{ '/guides/build-guide/' | relative_url }}">Build Guide</a> end to end.
